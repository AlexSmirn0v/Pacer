### Вход
Кадры с камеры, подключенной по *USB* к *Raspberry Pi*

### Выход
Публикация готового кадра после постобработки (если необходима) в топик `\feed`

### Действие
Считывание кадра с камеры с помощью *OpenCV*, обработка его для *SLAM* и перевод в формат сообщения для *ROS*
